# Hoàng Thổ

The design system of **English Center**. Its palette is built around the Thổ (earth) element: golden ochre as the accent,
earth brown for the frame, a light sand ground. Tokens live in `design-system/tokens.json` — the single source; `pnpm tokens`
generates `app/assets/css/tokens.css`, and `design-tokens.test.ts` re-checks contrast in both themes.

This Storybook renders the real components, layouts and pages from `app/` against a mocked API
(`.storybook/mocks`), with Nuxt runtime APIs replaced by `.storybook/nuxt/runtime.ts`. Use the toolbar to switch
theme and language, and the **Accessibility** panel to review each story.

## Why these colors

| Element (Ngũ hành) | How it is applied |
|---|---|
| **Thổ** — the owner's element | `ochre` (golden earth) carries the identity; `umber` (earth brown) frames navigation |
| **Hỏa nourishes Thổ** | the warm amber in `ochre`; red is not a brand color because red already means error |
| **Mộc restrains Thổ** | green is not an identity color — it only means *success*, in small, moss-toned areas |
| **Thổ restrains Thủy** | blue is reserved for *information* |

## The 10 color principles

1. **60 – 30 – 10** — `ground`/`surface` 60%, `umber` and text 30%, `ochre` 10%. See **Foundations › Colors**.
2. **Hierarchy** — `ochre` buttons / highlighted figure → headings → data → `ink-muted` labels → `ink-subtle` placeholders.
3. **Harmony** — analogous golden earth → burnt orange → brown; blue is the complement, used only for information.
4. **Contrast** — every text/background pair ≥ 4.5:1, control borders and focus ≥ 3:1, checked by a test.
5. **Consistency** — one state, one tone everywhere (see **Components › StatusTag**).
6. **Semantic color** — green success, red error, orange warning, blue information.
7. **Context** — an academic office: steady, warm, trustworthy; not playful.
8. **Saturation** — `ochre` is the most saturated color, so it covers 10% of the screen; semantic colors sit on `-soft` grounds.
9. **Accessibility** — tags always carry a shape and a label; the Accessibility addon runs on every story.
10. **Purpose over decoration** — money is never colored, tags are never decorative labels.

## What is here

- **Foundations** — colors, type scale, spacing, radius and shadows, read from `tokens.json`.
- **Components** — every component in `app/components`, including form dialogs and header controls.
- **Patterns** — the data table used across management screens.
- **Layouts** — the admin shell, the student portal and the sign-in frame.
- **Pages** — every screen of the app with sample data; some stories include interaction tests (**Interactions** panel).
